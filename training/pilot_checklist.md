# Pilotchecklista

## Före pilotstart

- [ ] 10 deltagare nominerade.
- [ ] 2–3 mål-appar valda.
- [ ] Testkonton skapade.
- [ ] Android-app installerad eller webb-URL tillgänglig.
- [ ] Supportkanal etablerad (t.ex. Slack/Teams).
- [ ] KPI-mall klar och delad.
- [ ] Roller satta: utbildningsansvarig, teknisk ansvarig, observatör.

## Under pilot

- [ ] Onboarding genomförd för samtliga deltagare.
- [ ] Minst ett scenario per deltagare loggat dagligen.
- [ ] Vanliga fel dokumenterade.
- [ ] Förbättringar till guide/mallar publiceras veckovis.
- [ ] Risker och incidenter flaggas samma dag.

## Efter pilot

- [ ] KPI-data sammanställd.
- [ ] Go/No-Go-beslut taget.
- [ ] Prioriterad backlog för v2 skapad.
- [ ] Lärdomar delade med team och ledning.
