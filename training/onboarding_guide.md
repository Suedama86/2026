# Onboarding-guide (45 minuter)

## Mål

Efter passet ska deltagaren kunna:
1. Starta en körning via URL + måltext.
2. Köra dry run och tolka planerade steg.
3. Köra skarp körning och verifiera resultat.

## Agenda

### 0–5 min: Kontext
- Vad verktyget gör.
- Vad det inte gör (begränsningar).

### 5–15 min: Grundflöde live
- Ange app-URL.
- Skriv mål: "Enable advanced mode with all features".
- Kör först i dry run.
- Kör sedan skarpt.

### 15–25 min: Säkerhet och kontroll
- När användaren ska stoppa körning.
- Hur man identifierar osäkra steg.
- Verifiering före/efter förändring.

### 25–40 min: Deltagarövning
- Deltagaren genomför 2 uppgifter med coachning.
- Tränaren noterar tid, fel och interventioner.

### 40–45 min: Summering
- 3 vanliga fel och hur de undviks.
- Nästa steg i pilotveckan.

## Kvalitetskriterier för godkänt onboardingpass

- Deltagaren klarar minst 1 fullständig körning utan handpåläggning.
- Deltagaren kan förklara skillnaden mellan dry run och skarp körning.
- Deltagaren verifierar resultatet i appen utan uppmaning.
